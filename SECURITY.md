# Segurança

Não relate vulnerabilidades em issues ou Discussions públicas. Use [Report a vulnerability](https://github.com/GUSTAVOHOOO/clipes/security/advisories/new) para enviar um relato privado pelo GitHub. Inclua os passos para reproduzir, o impacto e as versões afetadas, sem expor credenciais ou dados de terceiros. Os mantenedores poderão responder pelo próprio relato privado.

O recebimento depende de um administrador ativar o private vulnerability reporting, conforme a lista em [CONTRIBUTING.md](CONTRIBUTING.md).
