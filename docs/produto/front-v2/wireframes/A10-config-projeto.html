Notas

  1. Guarda de rota: se projects.current === null, navegar para #/config/projeto redireciona para #/config/provedores com aviso informativo.
  2. Ciência de Corte direto: campo somente leitura exibindo directMonetizationAck do Perfil de canal.
  3. Validação da faixa de corte: minUs > 0, minUs < maxUs e maxUs <= 180_000_000 (invalid_cut_range validado antes de enviar channel_profile.set).
  4. Estilo padrão de legenda: atualiza apenas o padrão para novos Cortes; Cortes já editados preservam sua própria revisão.
  5. Veto Somente local do Projeto: chama projects.local_only.set { enabled } e mantém o selo permanente visível na Barra Superior.
  6. Aviso de backup automático: exibido tanto na Barra de Status quanto no topo da aba Backups quando backups.settings.get().warning !== null; os dados são recarregados ao focar a aba ou após jobs (já que backups automáticos ainda não emitem core-progress).
  7. Bloqueio preventivo de restauração: quando há jobs ativos (jobs > 0), o botão "Restaurar" fica desabilitado com dica explícita para evitar erro project_busy.
  8. Restauração segura: <ConfirmDialog> abre com foco inicial em "Cancelar"; backups.restore cria automaticamente a cópia before-restore-* antes de substituir o banco. No estado vazio da lista de backups, exibe CTA "Criar primeiro backup agora".
