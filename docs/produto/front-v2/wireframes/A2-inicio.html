  2. Entrada na tela e atalhos: ao entrar em #/inicio, chama projects.recent, projects.current e assistant.status; se needsSetup === true na primeira abertura, direciona para #/assistente. Ctrl+N e Ctrl+O têm escopo restrito a esta tela.
  3. Decisão de wireframe (busca local): a especificação prevê filtro local quando há mais de 8 Projetos recentes; o campo aparece ilustrado no cabeçalho da lista para mostrar seu posicionamento, ficando oculto quando há 8 ou menos itens.
  4. Item indisponível no disco: quando available === false, combina ícone + selo textual "Indisponível no disco" (WCAG 1.4.1) e botão "Localizar pasta…" para apontar o novo caminho via projects.open.
  5. Carregamento (<Esqueleto>): exibe 4 linhas estruturais mantendo os botões primários operáveis; nunca renderiza estado vazio prematuro nem return null.
  6. Seletor nativo + campo editável (Consolidação §14): o botão "Escolher pasta…" abre o seletor do sistema operacional, mas o campo de texto permanece editável para acessibilidade e testes E2E. Nomes inválidos (ex.: a/b) exibem erro humano inline com aria-invalid sem expor CoreError.code.
  7. Mapeamento de erros acionáveis: <BannerErroCore> traduz outros códigos além de newer_project: project_busy → "Abrir Fila de Jobs"; project_open / migration / backup → "Tentar novamente"; library → mantém "Abrir pasta .clipes" utilizável. Detalhe técnico fica recolhido em <details>.
