Notas

  1. Shell mínimo (<Tela modoMinimo>): oculta seletor de Projeto, etapas e selos; mantém apenas identificação da janela e atalho discreto "Configurar depois" (assistant.complete { skipped: true }).
  2. FFmpeg: quando ausente ou incompleto, exibe botão primário "Baixar FFmpeg" que abre <ConfirmDialog> com tamanho, licença GPL e URL oficial antes de disparar components.download { id: "ffmpeg", confirmed: true }. No macOS sem entrada no manifesto, orienta usar o FFmpeg do sistema (components.ffmpeg.system).
  3. Tradução de hardware: a camada principal nunca expõe termos internos (int8_float16, handshake, CUDA), que ficam recolhidos em <details>Detalhes técnicos</details>. Sem placa NVIDIA compatível (ou com GPU AMD/Intel), explica claramente que a transcrição rodará no processador (CPU) com modelo mais leve.
  4. Orquestração do download: clicar em "Instalar motor recomendado" abre <ConfirmDialog> com tamanho e licença e encadeia components.worker.install → components.models.download → transcription.hardware.probe; Cancelar chama components.cancel.
  5. Passo 2 (assistant.detect): sonda portas loopback em até 800 ms (exibindo <Esqueleto> durante a busca). Se não encontrar servidores locais nem CLIs, exibe estado vazio neutro e foca a opção de chave de API. Claude Code CLI exibe selo explícito "Experimental".
  6. Consentimento e cofre: o botão "Testar conexão" (provider.test) só habilita após marcar o consentimento de envio de texto (provider.confirm / provider.cli.confirm). A chave vai direto para o cofre do sistema via provider.key.set.
  7. Decisão de wireframe (tela Concluído): a especificação (telas/A-shell-inicio-config.md Tela 3 §4) prevê que "Concluir configuração" chama assistant.default.set + assistant.complete { skipped: false } e navega para #/inicio. Esta variante representa o estado resumido de confirmação imediatamente antes de navegar para #/inicio.
