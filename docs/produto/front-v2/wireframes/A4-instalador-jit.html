Notas

  1. Desbloqueio automático: o componente verifica *.status e manifestos ao montar (mostrando <Esqueleto> de 2 linhas durante a consulta). Se tudo já estiver instalado e íntegro, devolve controle imediato à tela chamadora sem exibir este modal.
  2. Termo obrigatório para TTS (pocket-tts): o botão "Baixar e continuar" permanece desabilitado até o usuário marcar a concordância (termsAccepted: true), exigido por tts.models.download.
  3. Modos inline vs. modal: <InstaladorJustInTime> renderiza em <section aria-label="Instalação necessária"> quando embutido na tela (ex.: entrada por URL) ou em <Dialog> até 520 px quando acionado por botão de ferramenta.
  4. Estado parcial (partial): se yt-dlp já estiver instalado e apenas deno faltar (ou falhar js_runtime_missing), ou se pocket-tts estiver pronto faltando apenas o modelo do idioma, o já presente recebe selo "✓ Instalado" e apenas o faltante é baixado.
  5. Encadeamento de dependências (YuNet): se worker_installed === false, o componente informa que precisa do ambiente Python e encadeia components.worker.install { confirmed: true } → components.models.download { id: "yunet", confirmed: true }.
  6. Roteamento de cancelamento: downloads de yt-dlp, deno, worker, yunet e pocket-tts chamam components.cancel { id }; modelos e vozes TTS (tts:<model_id>) chamam exclusivamente tts.models.cancel { id }.
  7. Outros códigos de erro tratados: hash_mismatch / download → "Falha ao baixar ou verificar o arquivo. Você pode retomar de onde parou." + "Tentar novamente"; terms_acceptance_required → pede marcar os termos; unknown_component (ex.: yt-dlp/uv no macOS) → informa indisponibilidade automática no SO com orientação alternativa.
