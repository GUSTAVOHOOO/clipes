Notas

  1. Reabertura do Assistente: leva para #/assistente?passo=1 sem limpar perfis existentes; ao concluir, volta para #/config/provedores.
  2. Veto Somente local por tarefa: chama assistant.local_only.set; apenas proíbe envios externos (nunca troca o Provedor sozinho) e atualiza o selo na Barra Superior.
  3. Compatibilidade de Seleção: alimentado por provider.selection_state { task: "selection" } (omitido quando a Seleção usa CLI).
  4. Medir contexto real: provider.test { probeContext: true } só é habilitado em servidores locais loopback (probe_not_local caso contrário); nunca cobra USD.
  5. Claude Code CLI: exibe obrigatoriamente o selo textual "Experimental" e aviso de confirmação antes de provider.cli.confirm. Perfil legado ("legacy") pode ser editado e ter a chave removida, mas não removido pela API.
  6. Chave Groq e cofre: campos de chave nunca exibem o segredo salvo (apenas keyLastFour); remover chave de Perfil ou Groq abre <ConfirmDialog> antes de chamar *.key.remove.
  7. Guarda de rota de Projeto: acessar #/config/projeto sem Projeto aberto redireciona para #/config/provedores exibindo este banner informativo.
  8. Foco seguro em remoção: <ConfirmDialog> abre com foco inicial em "Cancelar" (proteção contra Enter acidental) e restaura o foco ao gatilho ao fechar.
