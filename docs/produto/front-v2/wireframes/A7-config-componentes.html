Notas

  1. Diagnóstico de hardware: traduz transcription.hardware.status sem jargões técnicos (int8_float16, handshake) fora de <details>.
  2. Agrupamento VAD (#279): chama transcription.grouping ({ auto: true } ou { enabled }); o aviso sobre CPU (+18%) vs GPU (+1 GB VRAM) fica sempre visível sem precisar expandir nada.
  3. Opções indisponíveis: opções com enabled: false continuam visíveis na lista com o motivo em PT-BR (reason) para o usuário entender por que não podem ser escolhidas.
  4. Progresso isolado por job: cada cartão escuta apenas seu próprio job em core-progress (ex.: "deno", "ffmpeg", "yunet", "tts:<id>").
  5. Catálogo assinado: components.catalog.check verifica assinatura Ed25519; em falha (catalog_signature_invalid / catalog_rollback), mantém o catálogo seguro embutido e exibe aviso.
  6. Vozes TTS: o checkbox de termo de uso proibido (termsAccepted: true) bloqueia o botão de download até ser marcado; cancelar chama tts.models.cancel (nunca components.cancel).
  7. Pastas e cache: components.settings.set exige caminhos absolutos e limite > 0 (invalid_settings caso contrário); campo editável acompanha o seletor nativo.
  8. Confirmação obrigatória: downloads de componentes/modelos usam <ConfirmDialog> com foco inicial em "Cancelar", enviando confirmed: true apenas após aceite. No estado ?estado=carregando, cada sub-aba exibe <Esqueleto>.
