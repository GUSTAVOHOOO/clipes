Notas

  1. Nome amigável do encoder: traduz h264_nvenc, h264_qsv, h264_amf, h264_videotoolbox e libx264 para nomes legíveis.
  2. Sonda real de 1 s: export.encoder.detect executa teste real de codificação de 1 s por candidato, atualiza passed e limpa stale.
  3. Escolha imediata: clicar em uma opção chama export.encoder.set { encoder } (ou { encoder: null } em Automático).
  4. WCAG 1.4.1: opções aprovadas vs. indisponíveis combinam ícone + rótulo textual (nunca só cor); opções não aprovadas ficam desabilitadas para evitar erro na exportação.
  5. Estado stale: quando a versão do FFmpeg ou hardware muda após a última detecção, mantém o encoder anterior utilizável com faixa de recomendação de novo teste.
  6. Chamada síncrona: export.encoder.detect não emite eventos core-progress; durante a sonda, o botão exibe carregamento e os rádios ficam desabilitados.
  7. Recuperação de FFmpeg ausente: <BannerErroCore> com CTA levando diretamente para #/config/componentes. No estado ?estado=carregando, exibe <Esqueleto> de 3 linhas.
