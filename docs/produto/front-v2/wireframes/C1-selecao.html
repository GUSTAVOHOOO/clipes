Notas

  1. Seletor de Fonte: lista apenas Fontes com transcript.state === "complete" (via sources.list + transcription.status); trocar atualiza ?fonte=:fonteId e recalcula selection.estimate.
  2. Tipo de vídeo (role="radiogroup"): herda channel_profile.get.videoKind e permite sobrescrever apenas para a execução atual; atualiza os pesos da Nota em tempo real.
  3. Aviso único de Corte direto: exibido quando guardrails.check retorna needsDirectNotice === true; clicar em Entendi o risco chama guardrails.ack_direct_notice e recolhe o aviso no Projeto.
  4. Faixa de duração em segundos (convertida para µs): valida minUs > 0, minUs < maxUs e maxUs <= 300 s; acima de 60 s mostra aviso não bloqueante sobre músicas reivindicadas em vídeos curtos.
  5. Sinais locais: se energy.measured === false, mostra botão Medir energia do áudio (energy.start); se chat.state === "none" && canFetch, mostra Buscar chat da live (chat.fetch).
  6. Compatibilidade da Janela de contexto (provider.selection_state / plan.state): full (15 min), reduced (janelas encurtadas) ou blocked (desabilita disparo e orienta reduzir duração ou trocar Perfil em #/config/provedores).
  7. <ResumoCustoPrivacidade> inline: sempre com tabular-nums; diferencia Local (loopback), Remoto (HTTPS) e CLI, e formatos US$ 0,00, ~US$ min – max, Consome cota do plano e Custo desconhecido.
  8. Seletor de Revisão da execução: visível quando run.revisions.length > 1; usa role="tablist" até 5 revisões ou <select> acima de 5, disparando selection.get { run, revision }.
  9. CTA Abrir bancada de revisão: navega para #/projeto/:id/cortes/revisao/:runId?rev=:n; se a execução concluiu com 0 candidatos, mostra estado vazio com CTA Refazer com outro Perfil.
  10. Ações por Janela: Refazer janela (selection.redo sem trocar perfil, apenas em failed/cancelled) e Refazer com outro Perfil (selection.estimate → <ConfirmDialog> → selection.redo { profileId, confirmed: true }, criando nova Revisão da execução).
  11. Guarda de custo em <ConfirmDialog>: obrigatório quando paid === true ou CLI; foco inicial no botão Cancelar para evitar disparo acidental com Enter.
  12. Atualização ao vivo por core-progress (ai:selection:*, selection:window, selection:done), sem setInterval.
  13. Cancelar seleção chama selection.cancel { run } (com confirmação se houver chamada paga em voo, avisando que pode ficar uncertain).
  14. Janela uncertain nunca é repetida às cegas: Resolver na Fila dispara jobs.estimate → <ConfirmDialog> para escolher entre jobs.retry { confirmed: true } ou jobs.discard.
  15. Decisão de wireframe / guarda de núcleo: enquanto houver janela uncertain, o botão Retomar pendentes (selection.resume) fica explicitamente bloqueado na UI. Se houver pausa de orçamento (run.budgetPause !== null), aparece banner equivalente com Ajustar orçamento e continuar (jobs.budget.continue).
  16. Guarda de rota: redireciona para #/inicio se não houver Projeto aberto; se nenhuma Fonte estiver transcrita, leva a #/projeto/:id/fontes.
  17. Fonte offline/changed: permite rodar seleção (a Transcrição vive no SQLite do Projeto), mas avisa que o preview 9:16 exigirá relocalização.
  18. Outros erros mapeados (context_too_small, profile_unavailable, vault/cli_auth_required, transcript_incomplete) seguem o mesmo container role="alert" sem código cru visível por padrão.
